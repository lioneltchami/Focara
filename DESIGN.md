## Overview

Focara helps people make screen recordings that guide attention to the cursor and clicks. The accepted logo pairs a dark navy wordmark with a focus-frame and cursor symbol. The symbol uses teal, blue, and violet; use the horizontal logo where the full name fits and the square icon in operating-system surfaces.

## Colors

Use navy for the wordmark and cursor. Keep the frame gradient moving from teal through blue to violet. The square app icon uses a cool, near-white field so the dark cursor and colored frame remain readable at small sizes.

## Typography

Use a clean, modern sans-serif. Set the Focara wordmark in title case with a confident, heavy weight. Interface copy stays compact and readable.

## Shapes

The focus frame uses thick strokes and rounded outer corners. Keep the center dot and cursor distinct at small sizes. Do not put the wordmark inside the square app icon.

## Do's and Don'ts

- Use `docs/images/focara-logo.png` for the approved horizontal logo.
- Use `build/icon.png` for the macOS and Windows app icon.
- Preserve the existing `.focus` project extension and use `com.lioneltchami.focara` as the app identifier.
- Do not reintroduce the ODAK / FOCUS wordmark; Odak and Focus are historical app names only.
